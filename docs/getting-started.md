# 方法一:把这件事交给 AI(推荐)

**这是最省事的方式。** 你不需要懂任何配置,把下面这段话复制给 AI
(ChatGPT / Claude / 豆包 / DeepSeek,或者手机上的任意 AI 助手),
它会一步一步带你做完。

## 复制这段话给 AI

```
我要给手机上的「运动世界校园」App 去掉广告,已经有一份别人做好的
广告域名屏蔽规则,但我完全不懂技术,请你一步一步教我。

我的情况:
- 手机系统:【安卓 / 苹果】
- 手机上有没有装 Clash:【有 / 没有 / 不知道】
- 我要不要翻墙:【要 / 不要】
- 我的文化程度:完全不懂技术,请用最通俗的话说,不要用术语

规则地址(如果要用,请告诉我怎么弄):
- Clash 规则文件:
  https://cdn.jsdelivr.net/gh/lukezzt8/SportWorld-CampusRun-AdBlock@main/rules/campusrun.yaml
- hosts 文件(给 AdGuard 等工具用):
  https://cdn.jsdelivr.net/gh/lukezzt8/SportWorld-CampusRun-AdBlock@main/rules/hosts.txt

请你:
1. 先问清楚我的情况,不要一上来就给我一堆配置
2. 每次只让我做一件事,做完确认了再进行下一步
3. 告诉我每一步在手机上的哪个位置点(比如"打开设置→找到应用→...")
4. 如果我说做不了或者找不到,换个方式教我
5. 遇到专业名词请用大白话解释

最后请告诉我:怎么确认成功了、以及万一出问题怎么恢复原样。
```

## 为什么推荐这个方法

- **不用下载任何东西** —— AI 会告诉你在手机上直接操作
- **出错能随时问** —— 卡在哪一步就把手机截图发给 AI
- **它会问你情况再动手** —— 不会像我给的这个文档一样"一刀切"

> **注意**:AI 可能会说"我看不到你的手机界面,你描述一下"。
> 这时候**直接截图发给它**就行,所有主流 AI 都支持发图。

# 方法二:只想屏蔽广告,不需要翻墙(3 步)

**适合**:手机上没有梯子,或者不打算用梯子。
**效果**:这个 App 的广告会消失,其他一切照旧。

## 需要先装一个东西

去应用商店或者 [这里](https://github.com/MetaCubeX/ClashMetaForAndroid/releases)
下载安装 **Clash Meta for Android**(免费)。

> 它看起来像个"翻墙软件",但你不用它翻墙,只用它的过滤功能。
> 装上以后不用管它,按下面做就行。

## 第 1 步:把规则文件弄到手机里

**最简单的办法** —— 用手机浏览器打开这个网址:

```
https://cdn.jsdelivr.net/gh/lukezzt8/SportWorld-CampusRun-AdBlock@main/configs/standalone.yaml
```

浏览器会显示一堆文字。**长按页面 → 全选 → 复制**,
然后打开手机上的「记事本」或「备忘录」,粘贴进去,**保存**,
文件名改成 `去广告.yaml`(或者任意英文名,比如 `ad.yaml`)。

**另一个办法** —— 如果你会用电脑:
在电脑上下载这个文件,用微信「文件传输助手」发到手机。

## 第 2 步:导入到 Clash

1. 打开 **Clash Meta for Android**
2. 点底部或侧边的「**配置**」(有的版本叫「Profiles」)
3. 点右下角的「**+**」加号
4. 选择「**从文件导入**」(有的版本叫「本地文件」)
5. 找到刚才保存的 `去广告.yaml`,选中它
6. 回到上一页,**点一下这个新出现的配置**,让它变成选中状态

## 第 3 步:打开开关

1. 回到 Clash 的主页
2. 找到那个大的开关(有的版本在顶部,有的在底部),**打开它**
3. 如果它问你要「VPN 权限」,点「**允许**」/「**确定**」
4. 看到「模式」选项的话,选「**规则**」(不要选「全局」)

**完成。** 现在打开「运动世界校园」,广告应该就没了。

### 怎么确认成功了

打开 Clash,找到「**连接**」或「**日志**」页面,打开 App 翻几页,然后:
搜 `snssdk`、`gdt`、`kuaishou` 这几个词,看到后面写着 `REJECT` 就成功了。

### 万一出问题

**关掉 Clash 那个大开关,一切立刻恢复正常。** 不会留下任何痕迹。

# 方法三:有梯子,想边翻墙边屏蔽

**适合**:你手机上已经在用 Clash 之类的东西翻墙。
**要点**:**不要**用方法二那个文件,那样会把你的节点弄丢。

## 你需要做的

把 `configs/standalone.yaml` 换成 `configs/prepend-rules.yaml`,
其它步骤和方法二一样。

**但这个文件不能直接导入**,它是要「合并」到你现有配置里的。

### 具体怎么做

**如果你用 Clash Verge Rev**:
1. 打开「订阅」页面
2. 找到「**规则覆写**」或「**Merge**」或「**全局扩展配置**」
3. 把 `prepend-rules.yaml` 里的内容**全部复制粘贴**进去
4. 保存 → 重新加载订阅

**如果你用 Clash Meta for Android**:
1. 设置里找「**覆写**」/「**Override**」
2. 新建一个覆写,把文件内容粘进去
3. 保存 → 重新加载订阅

**如果搞不定** → **回去用方法一,让 AI 教你**。
方法三最容易出错,尤其是一个叫 `MATCH` 的东西不能乱加。

# 其他设备的做法

## 如果你用 AdGuard(手机或电脑)

AdGuard 能直接吃 hosts 格式的规则:

1. 打开 AdGuard →「**过滤器**」→「**自定义过滤器**」
2. 添加这个网址:
   ```
   https://cdn.jsdelivr.net/gh/lukezzt8/SportWorld-CampusRun-AdBlock@main/rules/hosts.txt
   ```
3. 保存 → 更新过滤器

## 如果你用路由器(Pi-hole / AdGuard Home / OpenWrt)

在屏蔽列表里加入这个网址:

```
https://cdn.jsdelivr.net/gh/lukezzt8/SportWorld-CampusRun-AdBlock@main/rules/hosts.txt
```

## 如果你用「小火箭」「Surge」「Quantumult X」等

这些也能吃规则,但格式不一样。**把规则网址发给方法一里的 AI,让它帮你转换。**

# 常见问题

**Q:会不会影响我手机的其他功能?**
A:不会。这份规则只拦广告服务器,而且是精确到具体域名的。已经刻意避开了
登录、地图、推送、支付这些必须的域名。

**Q:会不会被 App 检测出来?**
A:不会。这个方法**完全不修改 App**,只是不让你连上广告服务器。
App 自己都不知道发生了什么。

**Q:App 更新后还有效吗?**
A:有效。规则是针对广告服务器域名的,跟 App 版本无关。

**Q:会不会封号?**
A:不会。你没有修改 App、没有破解任何功能,只是屏蔽了广告请求。

**Q:我怎么恢复原样?**
A:关掉 Clash 的开关就行。如果你改过配置,把配置文件里的规则删掉即可。

**Q:广告还有一些是去不掉?**
A:有些广告是 App 自己的服务器发过来的(和正常内容混在一起),
域名屏蔽拿它没办法。这种情况需要装 **GKD**(一个自动点击跳过广告的工具):
[github.com/gkd-kit/gkd](https://github.com/gkd-kit/gkd)

**Q:这些规则是哪来的?会不会有毒?**
A:规则是从 App 安装包里逆向分析出来的域名列表,就是一堆网址,
不含任何程序代码,不可能有毒。不信你可以打开文件看,里面全是这种格式:
```
DOMAIN-SUFFIX,snssdk.com,REJECT
```
意思就是"不连 snssdk.com 这个网址"。
